## Combat Summary

### Working Well
1. Target ID system working (99.7% valid targets)
2. Skill difficulty curve mostly on track
3. Enemy survival times reasonable (1.8-2.8 rounds)

### Bugs Found (Investigation Complete)

1. **"Unknown Weapon" (629 attacks)** - PLAYER LOGGING BUG
   - 326 from "Breaker", 63 from "Cipher", 39 from "Ghost"
   - Weapon data not being captured for player combat_action events
   - Damage IS dealt (5-16 per hit), just weapon name missing

2. **void_cultist 0 defeats** - DEFEAT EVENT NOT LOGGED
   - Cultists ARE taking damage and dying (HP goes to -10, status=defeated)
   - `enemy_defeat` event NOT generated when combat defeats enemy
   - Only "departed" (fled/scene-change) defeats are logged

3. **0 kills total** - SAME BUG AS #2
   - Combat kills aren't generating defeat events
   - All logged defeats are narrative "departed" not combat deaths

4. **66% null attribute rolls** - NPC ACTIONS (FIXED)
   - These are valid NPC action_resolution events (flee, hide, plead, etc.)
   - NPC actions don't require dice rolls, so `roll.attr/skill/d20` are null
   - **Fixed:** Skills analyzer now filters `roll.attr is None` (commit pending)
   - Before: 8,797 "rolls" (66% unskilled). After: 2,988 actual skill checks

5. **Brawl/Melee 100% success** - Small sample (21 and 14 uses)

### Balance Notes
1. Low-skill bucket overperforming (+15% vs expected)
2. Guile/Guns/Stealth all 98%+ success - very easy
3. Attunement is hardest at 54.8% (intentional - matches seed waste)
